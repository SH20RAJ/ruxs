# Feature Specification: Household Accounts & Shared Subscriptions

> **Canonical Document:** See detailed specification in [household.md](file:///Users/shaswatraj/Desktop/ruxx/docs/features/household.md).

## Summary
* Models co-living apartments, family dwellings, and roommate units.
* Connects multiple users to shared recurring services (Water, Milk, Tiffin).
* Enforces single primary financial liability while allowing delegated daily actions (skipping today's meal).
* Serves as the foundation for the Phase 5 Splitwise-style expense sharing layer.
