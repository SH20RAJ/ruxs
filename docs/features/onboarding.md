# Feature Specification: Onboarding (Vendor & Customer)

**Classification:** `[CONFIRMED PRODUCT REQUIREMENT]`

## 1. Vendor Onboarding
* **Business Profile:** Business name, owner phone, address, operating locality/pincode, UPI ID for receiving payments.
* **Service Definition:** Add beachhead services (Tiffin, Water), set unit pricing, define cutoff windows (e.g., 10:00 AM lunch).
* **Customer Import:** 1-Click contact import or CSV upload from WhatsApp chat list to bulk-invite existing subscribers.

## 2. Customer Onboarding
* **Contact Capture:** Phone number verification via WhatsApp OTP.
* **Address Mapping:** Society name, Tower/Wing, Floor, Flat number, and specific doorstep delivery instructions (e.g. "Leave in bag on handle").
* **WhatsApp Opt-In:** Explicit consent capture for daily morning fulfillment prompts.
